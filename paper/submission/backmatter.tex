\section*{Data availability statement}
This study uses the Human Mortality Database (\url{https://www.mortality.org}), June 2026
vintage. HMD requires free registration and its terms do not permit redistribution, so the
input files are not included with this article. The exact vintage is pinned by SHA-256 in
\texttt{data/MANIFEST.sha256} in the project repository, so every table can be tied to the
files it was computed from. The pre-registration document and its four addenda, the analysis
code, the per-cell result files and the \pkg{StMoMo} oracle dump are in that repository, whose
public URL is released on acceptance.
